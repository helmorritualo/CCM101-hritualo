# Checkpoint 8 – Mission Reflection

## 1. Which cloud platform impressed you the most?

Google Cloud Platform impressed me the most. Google developed Kubernetes from its internal Borg system, and Google Kubernetes Engine is the managed service built from that work. Vertex AI and Cloud TPU also show a clear focus on training and running machine learning workloads. AWS has a larger catalog, but GCP’s documented strength in AI and Kubernetes was the most distinctive finding in this mission.

## 2. What similarities exist among AWS, Azure, and GCP?

AWS, Azure, and GCP provide the same core cloud building blocks. Each platform offers virtual machines, object storage, virtual networks, identity and access management, managed SQL databases, and Kubernetes. They also use regions and availability zones, pay-as-you-go pricing, and web consoles for managing resources. The main differences are service names, integrations, and areas of specialization rather than the basic cloud model.

## 3. How do business requirements influence cloud platform selection?

Business requirements should decide the provider, not popularity. A university that already uses Windows Server, Microsoft 365, and Active Directory is a better fit for Azure because Microsoft Entra ID can keep the same identity environment. An AI research company needs high-performance training tools, so Vertex AI and Cloud TPU on Google Cloud are more appropriate. A startup and a global e-commerce company both fit AWS because of pay-as-you-go pricing, Auto Scaling, and worldwide content delivery.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that a consultant starts with the client’s problem and then matches it to official cloud services. The four client scenarios showed that AWS, Azure, and GCP can all host infrastructure, but only one usually fits the budget, software stack, or workload. Comparing equivalent services was necessary so the recommendation was based on documented capabilities instead of brand preference.

The portfolio now includes a third laboratory with provider research, a comparison table, client recommendations, a service-matching table, a decision matrix, KillerCoda evidence, and this reflection.
