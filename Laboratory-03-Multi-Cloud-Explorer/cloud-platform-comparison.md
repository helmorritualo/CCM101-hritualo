# Checkpoint 3 – Compare the Major Cloud Platforms

| Category | AWS | Microsoft Azure | Google Cloud Platform |
| --- | --- | --- | --- |
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon Elastic Compute Cloud (Amazon EC2) | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon Simple Storage Service (Amazon S3) | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon Virtual Private Cloud (Amazon VPC) | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | AWS Identity and Access Management (IAM) | Microsoft Entra ID | Cloud Identity and Access Management (Cloud IAM) |
| Primary Strength | Broadest and deepest cloud and AI service catalog, with the most extensive global infrastructure | Strong integration with Microsoft technologies, including Windows Server, Microsoft 365, and hybrid Active Directory identity | Strong AI/ML and Kubernetes capabilities, including Vertex AI, Cloud TPU, and Google Kubernetes Engine (GKE) |
| Ideal Organizations | Startups, enterprises, governments, and organizations that need a wide range of cloud services | Organizations that already use Microsoft products and need hybrid identity and Windows workloads | Organizations focused on artificial intelligence, machine learning, data analytics, and Kubernetes |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS offers the broadest range of services.** AWS official documentation describes it as the world’s most comprehensive and broadly adopted cloud, with the broadest and deepest set of cloud and AI capabilities and a portfolio of more than 240 services covering compute, storage, databases, networking, analytics, security, and other categories. This documented service breadth is larger than the catalogs presented by Azure and Google Cloud for equivalent core infrastructure areas.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure best integrates with Microsoft technologies.** Azure Virtual Machines support Windows Server workloads, and Microsoft Entra ID is the identity service used with Microsoft 365 and hybrid Active Directory through Microsoft Entra Connect directory synchronization. Because the university-style Microsoft stack already depends on these products, Azure is the provider whose official services are designed to extend that environment into the cloud.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform is strongest in Artificial Intelligence and Kubernetes.** Google developed Kubernetes from its internal Borg system, and Google Kubernetes Engine is Google Cloud’s managed Kubernetes service. Google Cloud also provides Vertex AI for training and deploying machine learning models and Cloud TPU accelerators for high-performance AI training and inference.

### 4. Which cloud platform would you personally choose and why?

**I would personally choose AWS.** It has been offering cloud infrastructure since 2006 and officially positions itself as the most comprehensive cloud platform, which is useful when a project may later need many different services. AWS also documents a large global infrastructure of Regions and Availability Zones, so the same platform can support both small learning projects and production systems that need high availability.
