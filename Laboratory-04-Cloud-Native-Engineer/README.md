# Laboratory 04: Cloud-Native Engineer

## Mission Overview

Laboratory Activity 4, "Mission 4: The Cloud-Native Engineer," examines the shift from traditional virtual machines to containers. The activity first compares virtualization with containerization for a CloudNova Technologies client whose virtual machines boot slowly and consume more RAM than their web applications need. Later checkpoints will use a KillerCoda Docker environment to pull, run, manage, and remove a containerized Nginx web server.

This laboratory continues the CCM101 Cloud Computing portfolio by adding container documentation, command evidence, and a mission reflection.

## Objectives

The objectives of this laboratory are to:

- Differentiate between traditional virtual machines (VMs) and containers.
- Access a Docker-enabled cloud environment using KillerCoda.
- Execute fundamental Docker CLI commands.
- Pull, run, manage, and terminate a containerized Nginx application.
- Create professional technical documentation of container operations using Markdown.
- Continue developing a well-organized GitHub Cloud Computing portfolio.
