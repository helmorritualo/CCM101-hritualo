# Reflection

Laboratory Activity 1 introduced me to working with a cloud-based Linux environment through the KillerCoda Playground. Before proceeding with more advanced cloud computing activities, I needed to become comfortable with basic Linux commands, user management, file organization, and system information gathering.

One of the main things I learned from this activity was how to create and configure a Linux user with a home directory, Bash shell, and sudo privileges. I also practiced using commands such as `whoami`, `pwd`, `hostname`, `lscpu`, `free`, and `df` to understand the environment where my applications and services would run.

I also learned that proper organization and documentation are important when working with technical projects. Creating directories, Markdown files, and a GitHub repository provides a structured way to keep track of laboratory activities and evidence of completed work.

The activity helped me become more familiar with using the Linux terminal and gave me a foundation for future cloud computing tasks. I expect the skills I practiced in this laboratory to be useful when working with servers, containers, cloud infrastructure, and other technologies throughout the course.

## Key Takeaway

My main takeaway from this laboratory is that understanding the Linux environment and knowing how to document technical work are important foundational skills for cloud computing.
