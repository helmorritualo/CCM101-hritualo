# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory activity focused on cloud object storage and the deployment of an S3-compatible storage server using MinIO. The task involved deploying MinIO with Docker, accessing its Web Console through a forwarded port, creating a storage bucket named `client-photos`, and uploading a sample object.

## Objectives

- Understand the differences between Block Storage, File Storage, and Object Storage.
- Deploy an S3-compatible object storage server using Docker.
- Access a containerized cloud service through a web interface.
- Create an object storage bucket and upload objects.
- Document cloud storage deployment and configuration using Markdown.

## Tools Used

## Skills Learned

- Deploying containerized cloud services with Docker.
- Configuring containers using environment variables.
- Working with exposed and forwarded network ports.
- Accessing and managing an object storage service through a web interface.
- Creating buckets and uploading objects.
- Documenting technical configurations and cloud operations using Markdown.
