# Checkpoint 7: Mission Reflection

## 1\. Which cloud infrastructure component do you think is the most important? Why?

I consider networking the most important cloud infrastructure component because it allows users, applications, compute resources, and storage services to communicate. Even if a system has powerful servers and enough storage, those resources are not useful when traffic cannot reach them securely. During the architecture activity, I realized that a well-planned network also defines boundaries and helps control access to cloud resources.

## 2\. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, flexible, and efficient operating environment for servers and virtual machines. It also includes command-line tools that administrators can use to inspect resources, manage services, configure networks, and troubleshoot problems. Using Ubuntu in KillerCoda helped me understand how cloud engineers examine the condition of an infrastructure environment.

## 3\. Why is technical documentation important before deploying infrastructure?

Technical documentation gives the team a clear reference before deployment. It explains the components, configuration decisions, expected connections, and purpose of the architecture. This can reduce misunderstandings, make review easier, and help identify missing requirements before resources are created. Documentation also supports future maintenance because another developer or administrator can understand the original design.

## 4\. What new skills did you learn during this laboratory activity?

I learned how to inspect Linux system information using commands for the operating system, CPU, memory, disks, filesystems, hostname, and IP addresses. I also improved my understanding of compute, storage, networking, and IAM. Comparing AWS, Azure, and GCP taught me to evaluate equivalent services instead of focusing only on product names. Creating the AWS diagram in [Draw.io](https://www.drawio.com/) improved my ability to translate written requirements into a logical visual design.

## 5\. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio now contains a complete cloud infrastructure laboratory with reports, screenshot evidence, provider research, an architecture diagram, and technical documentation. The repository shows not only the final outputs but also my ability to organize files and use meaningful commits. It provides practical evidence of my Linux, cloud, documentation, diagramming, and version-control skills.
